# rxlibs - numpy / scipy / pandas style native plugins for CREXX Level B

Native libraries callable **directly from CREXX Level B programs** (no Python interpreter involved):

* `rxnumpy`  - n-d float64/int64 arrays, linalg, FFT, legacy MT19937 and PCG64 `default_rng` (bit-exact), fancy/boolean indexing, n-d matmul   (`rxnumpy..np_*`)
* `rxscipy`  - special functions (gamma, erf, erfinv, betainc, gammainc ... to ~1e-13), 12 distributions (norm t chi2 f gamma beta expon uniform lognorm binom poisson geom: pdf/pmf cdf sf ppf mean var rvs), describe/skew/kurtosis/zscore/percentile/correlate, t tests, chi2_contingency, pearsonr, spearmanr, linregress, integration, interpolation, cubic splines, fits; plus the Level B module `rxspalg` with callback solvers (minimize, root, quad, solve_ivp, curve_fit)
* `rxpandas` - DataFrame-like tables: CSV, index (range/labelled), multi-key sort/groupby, merge (inner/left/right/outer), value_counts, pivot, ISO datetime (`rxpandas..pd_*`)

Design (handle model, errors, memory, build/install, roadmap): [docs/DESIGN.md](docs/DESIGN.md).
Manual (concept, install, handle model, full function reference with verified examples, callbacks and solvers, worked examples, limits, performance): [docs/Rxlibs-Guide.pdf](docs/Rxlibs-Guide.pdf) / [.docx](docs/Rxlibs-Guide.docx); the example programs are in `docs/examples/`.

## Quick start

    export CREXX_ROOT=/path/to/crexx            # source tree with rxpa/crexxpa.h (default /home/claude/src/crexx)
    export CREXX_GENERATED=$CREXX_ROOT/cmake-build-release/generated   # crexx_version.h
    export CREXX_VM=/path/to/bin/crexx          # the compiler driver of the CREXX build that will run the code
    scripts/build.sh                            # -> build/plugins/{rxnumpy,rxscipy,rxpandas}.rxplugin
    scripts/run.sh rxnumpy/examples/demo.crexx  # compile (-i plugin dir) and run (-l each plugin)
    scripts/runtests.sh                         # expected outputs are generated by CPython + numpy/scipy/pandas

```rexx
options levelb floats_binary
import rxnumpy
a = rxnumpy..np_array("[[1.0, 2.0], [3.0, 4.0]]")
say rxnumpy..np_tolist(rxnumpy..np_dot(a, a))      /* [[7.0, 10.0], [15.0, 22.0]] */
say rxnumpy..np_det(a)
```

Notes: write helper procedures plus `main: procedure = .int` (code after helper procedures outside `main` is not run);
variables assigned inside a `do` block are block-local; floating arguments need `options levelb floats_binary`.

## Tests

`scripts/runtests.sh` builds the Level B libraries (`scripts/buildlib.sh`), then runs every `*/tests/t_*.crexx` and diffs against `*.expected`,
regenerated by `gen_*.py` from real numpy 2.5.3 / scipy 1.18.1 / pandas 3.0.5 (floating output rounded to 6-9 decimals).
Coverage (9 programs, 9/9 pass): rxnumpy 4 (elementwise/broadcast/reductions/slicing/sort/dot, linalg, fft + legacy random streams,
`t_pcg_idx`: default_rng random/integers/normal/exponential/choice/shuffle/permutation bit for bit, boolean/integer indexing, where, unique, stack, n-d matmul/dot/tensordot),
rxscipy 3 (special/stats/interp/polyfit/cubic spline; `t_stats` (136 lines): gamma/erf/erfinv/betainc/gammainc, pdf/cdf/sf/ppf/mean/var of the 12 distributions, `sp_rvs` against `np.random.seed(s); dist.rvs(size=5)` for 16 parameter sets,
describe, skew, kurtosis, zscore, percentile, correlate (valid/same/full), ttest_1samp/ind/welch, pearsonr, spearmanr (ties), linregress, chi2_contingency (with and without Yates);
`t_opt`: brentq, newton, quad, Nelder-Mead, BFGS, solve_ivp incl. the default RK45 step sequence, curve_fit with covariance),
rxpandas 2 (base table ops; `t_pandas2`: multi-key groupby/sort, merge variants, value_counts, pivot, index, datetime).
`bench/accuracy.py` compares ~1100 points of the special functions and distributions with scipy (0 above 1e-12 relative, worst 1.1e-13).
The manual (built in `/home/claude/work/doc_rxlibs` with `run.sh`) is verified by its `examples_check.py`, which re-runs 235 items: 8 listings, the 225 function reference examples and 2 CPython twin programs (`docs/examples/ex_*.py`).

Distributions: `rxscipy..sp_pdf|sp_pmf|sp_cdf|sp_sf|sp_ppf(dist = .string, x, a, b, loc, scale)`, `sp_mean|sp_var(dist, a, b, loc, scale)`, `sp_seed(seed)` + `sp_rvs(dist, size, a, b, loc, scale)`
with `(a, b)` the scipy shape parameters (t: df; chi2: df; f: dfn, dfd; gamma: a; beta: a, b; lognorm: s; binom: n, p; poisson: mu; geom: p).
`sp_rvs` uses the legacy MT19937 stream with numpy's legacy algorithms: after `sp_seed(s)` it equals `np.random.seed(s); dist.rvs(size=n)` bit for bit for every distribution except
binom with n*min(p,1-p) > 30 and poisson with mu >= 10 (numpy uses BTPE / PTRS there; `sp_rvs` samples by inversion: same distribution, not the same numbers).
The rxscipy stream is separate from `np_rand_seed` (each plugin library has its own generator state).

## Speed
`bench/run_bench.py` times the plugin calls against CPython numpy 2.5.3 / scipy 1.18.1 / pandas 3.0.5 for several sizes: serialised runs (CPython, then CREXX, case after case),
5 repetitions of N calls each, median, BLAS limited to one thread (the plugins are single threaded); setup is outside the timed region; results in `bench/results.csv`
(shared 2-core Linux VM, so absolute numbers vary by tens of percent; chapter 11 of the manual discusses them).
`quad` and `minimize` are Level B callback algorithms (every function evaluation is a CREXX method call), `groupby` is pandas `df.groupby("k")["v"].sum()` on 100 keys.

The native kernels are plain C loops (no SIMD, no BLAS): the plugin is 1-4x numpy for sum and fft, 8-16x for matmul and sort, up to 100x for solve at n=500, and faster for small calls where the Python/numpy/pandas dispatch dominates (sum of 1000, groupby of 1000 rows).
The plugin sum uses numpy's pairwise summation, so results agree with numpy bit for bit. Against the Python-in-CREXX interpreter (`../crexx/py`, built-in numpy) the plugin is ~220x (matmul 100x100), ~850x (sum of 10^6) and ~43000x (fft 1024) faster.

## Not included / limits

See "Status" and "Roadmap" in docs/DESIGN.md. Callback solvers are interface based Level B code (slower than native, no Python); BFGS uses a
central-difference gradient and an Armijo backtracking line search (same minimum as scipy, not the same iterates); `sp_quad` has no infinite limits or
singularity extrapolation (QUADPACK qags epsilon algorithm); `Generator` supports `random/integers/normal/exponential/choice (no p)/shuffle/permutation`
(1-d `choice`, `integers` with exclusive high); comparisons treat `inf - inf` as unequal; float64/int64 dtypes only (masks are int64 0/1 arrays).
