# rxlibs - numpy / scipy / pandas style native plugins for CREXX Level B

Native libraries callable **directly from CREXX Level B programs** (no Python interpreter involved):

* `rxnumpy`  - n-d float64/int64 arrays, linalg, FFT, legacy MT19937 and PCG64 `default_rng` (bit-exact), fancy/boolean indexing, n-d matmul   (`rxnumpy..np_*`)
* `rxscipy`  - special functions, distributions, integration, interpolation, cubic splines, fits, tests; plus the Level B module `rxspalg` with callback solvers (minimize, root, quad, solve_ivp, curve_fit)
* `rxpandas` - DataFrame-like tables: CSV, index (range/labelled), multi-key sort/groupby, merge (inner/left/right/outer), value_counts, pivot, ISO datetime (`rxpandas..pd_*`)

Design (handle model, errors, memory, build/install, roadmap): [docs/DESIGN.md](docs/DESIGN.md).

## Quick start

    export CREXX_ROOT=/path/to/crexx            # source tree with rxpa/crexxpa.h (default /home/claude/src/crexx)
    export CREXX_GENERATED=$CREXX_ROOT/cmake-build-release/generated   # crexx_version.h
    export CREXX_VM=/path/to/bin/crexx          # the compiler driver of the CREXX build that will run the code
    scripts/build.sh                            # -> build/plugins/{rxnumpy,rxscipy,rxpandas}.rxplugin
    scripts/run.sh rxnumpy/examples/demo.crexx  # compile (-i plugin dir) and run (-l each plugin)
    scripts/runtests.sh                         # expected outputs are generated by CPython + numpy/scipy/pandas

```rexx
options levelb floats_binary
import rxnumpy
a = rxnumpy..np_array("[[1.0, 2.0], [3.0, 4.0]]")
say rxnumpy..np_tolist(rxnumpy..np_dot(a, a))      /* [[7.0, 10.0], [15.0, 22.0]] */
say rxnumpy..np_det(a)
```

Notes: write helper procedures plus `main: procedure = .int` (code after helper procedures outside `main` is not run);
variables assigned inside a `do` block are block-local; floating arguments need `options levelb floats_binary`.

## Tests

`scripts/runtests.sh` builds the Level B libraries (`scripts/buildlib.sh`), then runs every `*/tests/t_*.crexx` and diffs against `*.expected`,
regenerated by `gen_*.py` from real numpy 2.5.3 / scipy 1.18.1 / pandas 3.0.5 (floating output rounded to 6-9 decimals).
Coverage (8 programs): rxnumpy 4 (elementwise/broadcast/reductions/slicing/sort/dot, linalg, fft + legacy random streams,
`t_pcg_idx`: default_rng random/integers/normal/exponential/choice/shuffle/permutation bit for bit, boolean/integer indexing, where, unique, stack, n-d matmul/dot/tensordot),
rxscipy 2 (special/stats/interp/polyfit/cubic spline; `t_opt`: brentq, newton, quad, Nelder-Mead, BFGS, solve_ivp incl. the default RK45 step sequence, curve_fit with covariance),
rxpandas 2 (base table ops; `t_pandas2`: multi-key groupby/sort, merge variants, value_counts, pivot, index, datetime).

## Speed
Measured on this machine (Linux x86-64, `-O2`), CREXX patched VM; plugin timings from `rxnumpy/bench/bench.crexx`
(20/20/200 repetitions, includes the CREXX call overhead), Python-in-CREXX (`../crexx/py`, built-in numpy) timed with `time.time()`
in `rxnumpy/bench/bench_py.py`-style scripts:

| operation | rxnumpy plugin | Python-in-CREXX numpy | speed-up |
|---|---|---|---|
| matmul 100x100 | 0.75 ms | 164 ms | ~220x |
| sum of 10^6 floats | 0.6 ms | 510 ms | ~850x |
| fft 1024 (complex result) | 0.037 ms | 1600 ms | ~43000x |

(The plugin sum uses numpy's pairwise summation, so results agree with numpy bit for bit; the matmul is a plain i-k-j loop, about 2.6 GFlop/s.)

## Not included / limits

See "Status" and "Roadmap" in docs/DESIGN.md. Callback solvers are interface based Level B code (slower than native, no Python); BFGS uses a
central-difference gradient and an Armijo backtracking line search (same minimum as scipy, not the same iterates); `sp_quad` has no infinite limits or
singularity extrapolation (QUADPACK qags epsilon algorithm); `Generator` supports `random/integers/normal/exponential/choice (no p)/shuffle/permutation`
(1-d `choice`, `integers` with exclusive high); comparisons treat `inf - inf` as unequal; float64/int64 dtypes only (masks are int64 0/1 arrays).
