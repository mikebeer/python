# Python subset - specification

Goal: run ordinary Python 3 programs of the kind in `tests/` and print exactly what CPython 3 prints.
Two implementations share this spec and the tests:

* `c/`      strict C89 (see mikebeer/apl, mikebeer/smalltalk/c): one amalgamated file, all functions static,
            no `//`, no mixed declarations, no `long long`, no stdint.h, EBCDIC-safe character handling,
            POSIX only under `-DST_POSIX`-style flag (`-DPY_POSIX`). Must be portable to VM/370.
* `crexx/`  CREXX Level B (see mikebeer/snobol, mikebeer/smalltalk).

## Language
Indentation blocks (spaces/tabs, INDENT/DEDENT, implicit line joining in brackets, `\` continuation),
`if/elif/else`, `while/else`, `for/else`, `break/continue/pass`, `def` (defaults, `*args`, `**kw`, keyword-only
after `*`, call-site `*`/`**`), `lambda`, closures, `global`, `nonlocal`, `return`, `class` (multiple
inheritance is NOT required; single inheritance, `super()`, class attrs, `@property`, `@staticmethod`,
`@classmethod`, dunder methods: `__init__ __str__ __repr__ __eq__ __ne__ __lt__ __le__ __gt__ __ge__ __add__
__sub__ __mul__ __neg__ __len__ __getitem__ __setitem__ __contains__ __iter__ __next__ __call__ __bool__
__hash__ __enter__ __exit__`), `with`, `try/except/else/finally`, `raise` (with `from` ignored), `assert`,
`del`, generators (`yield`, `yield from`), generator expressions, list/dict/set comprehensions, conditional
expressions, chained comparisons, `in/not in/is/is not`, `and/or/not`, augmented assignment, tuple
unpacking (with one starred target), slicing with step, f-strings (`!r !s`, format specs `d f s x b o e ,`,
width/fill/align), `%` formatting, `str.format`, `import` / `from .. import` / `import .. as`
(built-in modules only: `math random sys time`; `numpy` later), decorators on functions/methods (simple
`@name`), docstrings ignored, `print(sep=, end=)`.
Not required: async, metaclasses, multiple inheritance, `exec/eval`, `import` of files, decorators with
arguments on classes, `match`, walrus, type hints may be parsed and ignored.

## Values
`int` is unbounded (big integers), `float` (double), `bool`, `str` (bytes; UTF-8 passes through, `len` counts
bytes - acceptable difference), `None`, `list`, `tuple`, `dict` (insertion ordered), `set`, `range`, functions,
classes, instances, bound methods, generators, exceptions. Float printing is the shortest round-trip repr
(`0.30000000000000004`, `1e+22`, `1e-05`).

## Builtins
`print len range int float str bool list tuple dict set repr abs min max sum sorted reversed enumerate zip map
filter any all round divmod pow chr ord hex oct bin isinstance issubclass type hasattr getattr setattr
callable iter next id hash input open(read/write text) super object`, exceptions hierarchy (`BaseException
Exception ArithmeticError ZeroDivisionError LookupError IndexError KeyError ValueError TypeError NameError
AttributeError RuntimeError StopIteration AssertionError SystemExit NotImplementedError OverflowError
RecursionError`), methods of str/list/dict/set/tuple as used in `tests/`.

## Errors
Uncaught exception: print `Traceback (most recent call last):` (simplified) and `Name: message` to stderr, exit 1.
Messages of the common exceptions match CPython (e.g. `division by zero`, `list index out of range`,
`invalid literal for int() with base 10: 'abc'`, `name 'x' is not defined`).

## Usage
`py file.py [args]`, `py` (REPL on stdin), `py -c "code"`.

## Tests
`tests/NN_name.py` + `.out` (generated by CPython 3). `tests/run_tests.sh <interpreter>`.

## numpy subset (tests/11_numpy.py)
`import numpy as np` provides a native subset: `ndarray` (int64/float64/bool; N-d, row-major) with `shape ndim size
dtype T`, `len`, iteration over first axis, indexing (ints, slices with step, negative, `a[i, j]`, `a[:, j]`, boolean
mask, integer list), slice/element assignment, broadcasting `+ - * / // % **` and comparisons, unary `-`, `@`,
`tolist copy reshape flatten astype sum mean min max prod argmax argmin cumsum std var round dot`
(with `axis` for sum/mean/min/max), and module functions `array zeros ones full eye arange linspace sqrt abs exp
sin cos log where concatenate vstack hstack sort unique dot matmul transpose diag trace cumsum maximum minimum
clip any all allclose array_equal median std var round pi e`. `print(array)` uses numpy's layout for int and
bool arrays (space separated, right-aligned to the widest element, nested brackets, one row per line for 2-d);
float arrays print like numpy where feasible. Scalars returned by reductions are plain Python int/float/bool.
