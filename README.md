# Python subset interpreters

A Python 3 subset (see [SPEC.md](SPEC.md)) in two implementations that share one test corpus
(`tests/*.py`, expected output generated by CPython 3):

| Dir | Language | Notes |
|-----|----------|-------|
| `c/` | strict C89, one amalgamated file | portable (VM/370 target); `make -C c`, `./c/py file.py` |
| `crexx/` | CREXX Level B | `./crexx/py file.py` (compiles on first use, a few minutes; later runs about 0.4 s with the patched VM, see `crexx/STARTUP.md`) |

Test: `tests/run_tests.sh ./c/py` or `tests/run_tests.sh ./crexx/py` (69 numbered tests, 70 programs with the companion 34b: the C version passes all, the CREXX version all but `34_hash64`, a C-only set-order test listed in `tests/crexx_skip.txt`). `make -C c test embed-test deck-test deck-embed-test strict` runs the portability checks as well.

Features (both interpreters unless noted): the language incl. classes, generators, comprehensions, `__new__` and subclasses of the built-in types, complex numbers, `bytes`/`bytearray`, `struct`, `cmath`, `re` and `json` (native C code in `c/`, Python in `pylib/` for CREXX), `socket`/`select` (C: only with `-DPY_POSIX`; CREXX: rxsocket), the usual standard library, NumPy (dtype objects, complex128, `numpy.fft`, complex eigenvalues), pandas (incl. Timestamp, Timedelta, DatetimeIndex, `date_range`, `to_datetime`, `.dt`, `resample`, time zones via `zoneinfo`, `.plot()`), a `matplotlib.pyplot` subset that writes SVG (`savefig('x.svg')`) with matplotlib's limits, ticks and tick labels, and SciPy (incl. `scipy.fft`, `signal.freqz/hilbert/spectrogram/welch`). For VM/370 the C version builds as 71-column card decks (`make deck`), with the Python libraries embedded in the binary (`-DPY_EMBED_LIBS`, `make embed`) and a host adapter for the operating-system calls; see `c/PORTING.md`.

Speed of the C version against CPython 3.13: fib(27) 0.06 s vs 0.05 s (fib(25): 0.02 s vs 0.03 s), 3M-iteration loop 0.53 s vs 0.95 s, list/dict work 0.23 s vs 0.27 s, native `re` and `json` about as fast as CPython's. The CREXX version is a teaching/scripting tool (fib(25) about 4.7 s). Set `CREXX_VM` to the patched virtual machine to cut its start-up from about 3 s to 0.4 s. Gaps are listed in each subdirectory README and in the manual (Chapter 12).

## rxlibs: native numpy / scipy / pandas style plugins for CREXX

[`rxlibs/`](rxlibs/README.md) holds three CREXX native plugins that Level B programs call directly, without the Python interpreter:
`rxnumpy` (n-d arrays, linalg, FFT, exact legacy random streams), `rxscipy` (special functions, distributions, integration, interpolation, fits)
and `rxpandas` (tables with CSV, filter, sort, groupby, merge, describe). The C89 numeric core is factored from `c/src/p7_*.c`;
tests compare against CPython with numpy, scipy and pandas. Design and build: [rxlibs/docs/DESIGN.md](rxlibs/docs/DESIGN.md).

## Manual

The user manual, [Python-CREXX-Guide.pdf](docs/Python-CREXX-Guide.pdf) (also as .docx), covers both interpreters: installing, the language, built-ins, standard library, NumPy, pandas, SciPy, errors, internals, measured performance, restrictions, the C/CREXX differences and porting to VM/370 (13 chapters and appendices, about 130 pages, Build 13).
